# You don't need an un-gameable measure. You need an un-gameable game.

> The thesis in the title is the aspiration; the honest form the code supports is narrower and stated
> up front in Section 1: not "un-gameable" but "no *free* game" — gaming carries a strictly positive,
> priced cost floor. Ready-for-critique, revised 2026-08-07 after an adversarial council review that
> caught the original rounding up its own thesis. Status discipline throughout: built / designed /
> open, never rounded up. Every load-bearing code claim carries a file:line verified against source.

## 1. The claim, stated honestly before anything else

The reframe this paper defends is real: you do not fix a gameable value measure with a better measure,
you change the game so that gaming loses money. But the strong form of the slogan ("un-gameable") is
itself the kind of overclaim the slogan accuses others of, so here is the precise version, and the rest
of the paper earns exactly this and no more:

- **Interior value scoring is worth-blind** (Section 2): every graph-internal discriminant the
  reference node ships scores a genuine collaboration and a topology-matched wash the same.
- **Measurement relocates to the boundary, but the boundary is a recursion, not a terminus**
  (Sections 3 and 4a): the boundary signal is un-gameable only if the minds producing it are
  independent, which is established by the same measure one level down.
- **The game the code supports has no *free* attack, not no attack** (Sections 5 and 6): a strictly
  closed wash-ring is negative-EV; the cheapest real attack is not the 51% cartel but a *semi-funded
  ring* that rents one independent identity per cell, and it leaks far below any majority.
- **The two things doing the actual work are unbuilt** (Section 7): the capital-independence *source*
  and the junk-challenge process. What is built is the accountant that prices the residual *given* them.

If you only read this section: the contribution is the *shape* of the solution and an honest map of
where it is not yet closed, not a proof that wash is solved.

## 2. Interior measurement is worth-blind (demonstrated, bounded)

The thing that cannot work is *self-referential* scoring: value read from the contribution graph's own
interior (topology, novelty, synergy). `node/examples/wash_sim.rs` builds a genuine four-mind
collaboration and a four-identity wash operation (distinct sybil keys, distinct novel content, the same
tree topology) and runs every shipped graph-internal discriminant. The output, including the wash-ring
variant that closes a cycle:

```
discriminant  | genuine | wash-tree | wash-ring | genuine vs wash-TREE
--------------+---------+-----------+-----------+---------------------
novelty       |   124   |    124    |    158    | BLIND (0.0%)
synergy       | 124.000 |  124.000  |  158.000  | BLIND (0.0%)
cycle_energy  |   0.000 |    0.000  |    4.000  | BLIND on tree; FIRES on ring
circulation   |     0   |      0    |      0    | BLIND (0.0%)
value_v8      |   0.000 |    0.000  |    0.000  | degenerate (0 for all; see note)
```

The substantive result is `novelty` and `synergy`: genuine and wash produce *identical nonzero* scores
(124/124). The cyclic defenses (`cycle_energy`, `circulation`) catch a *dumb* wash-ring but are blind to
a wash-*tree* that mimics honest topology. (`value_v8` reads 0.000 for genuine, wash, and ring alike:
that is a degenerate null-output on this toy fixture, the v8 outcome factor and standing floor zero
un-stood identities, so it demonstrates nothing about a trained v8's discriminating power and is not
part of the argument.)

Scope, honestly: this is 0.0% separation on a *matched-topology constructed case* (a 5% relative-
difference "BLIND" threshold, `wash_sim.rs:123`; genuine and wash content are generated by the same
function by construction). It is an existence proof that a competent wash *can* match the interior
signals, not a distributional claim about real corpora. And it is a statement about *worth-blind*
measures, not literally all interior measures: Section 7 records a learned `v(S)` reaching ~0.60 on
honest rich-feature labels, so interior features carry *some* worth signal. The defensible claim: no
worth-blind measure can separate genuine from wash, because they differ only in content-worth.

## 3. Measurement relocates to the boundary

If the interior is worth-blind, measure at the edge: whether something *outside* the minting system
realized use of the contribution. In Noesis the boundary signal is realized use by *capital-independent*
minds. Independence is anchored in capital rather than personhood, because personhood is a capturable
authority and capital is harder to forge cheaply.

Stated at the point of the claim, not deferred to a status section: what is **built** is the vesting
gate that *consumes* this signal (`node/src/lib.rs:7306`, `pub mod vesting::independent_use_gate`). What
is **not built** is the capital-cluster *source* that would establish "distinct origin" on-chain
(`lib.rs:7305`, verbatim: "The source of that signal (a capital-cluster oracle) is itself unbuilt"). So
"you can check the using identity's capital is a distinct origin, on-chain, no opinion" is a *design
target*, not a current fact. Today the gate is a single per-cell cluster-id comparison
(`lib.rs:7351`): `(Some(a), Some(b)) => a != b`. That is also why capital-independence is *pricing,
not Sybil resistance*: a whale who splits real capital into distinct clusters passes `a != b` on every
edge and vests fully. It converts a free Sybil into a per-identity capital toll; it does not exclude it.

## 4. The load-bearing move, and where it recurses

### 4a. The boundary is a recursion, not a terminus (the central honest correction)

The original draft of this paper called the boundary "the only place value cannot be gamed." That is
false, and the project's own foundation doc says so. `DESIGN-mind-scarcity-asymmetry.md:27-29`,
verbatim:

> the defense does not bottom out in a non-oracle fact. It **recurses**: the signal is un-gameable iff
> the minds producing it are independent, which is verified by the signal. One object, two sides — but
> the seam between the sides is a loop, and a loop is what an attacker probes at its cheapest point.

"Another mind built on this" is evidence of value only if that mind is itself genuine and independent,
which is the same question one hop down. Moving measurement to the boundary does not dissolve Goodhart;
it *relocates it one level out and raises its price*. That price is the whole contribution, and it is a
comparative claim, not an absolute one:

- **Interior gaming is free**: 0.0% structural separation (Section 2), so junk costs nothing to make
  look novel.
- **Boundary gaming has a strictly positive per-cell floor**: to make a cell vest, the attacker must
  produce at least one downstream builder in a *distinct* capital cluster.

### 4b. Verifiable and expensive-to-forge coincide only when engineered to

The original draft claimed "verifiable = expensive-to-forge, one property." They are not one property
in general: a signature is verifiable and cheap to forge if you hold the key. They *coincide* only when
a mechanism is engineered so the checked object equals the costly object. Bitcoin's proof-of-work is the
special case where they coincide by physics (a fixed hash target), and it secures *ordering and
issuance*, not the *worth* a coin buys, which is the layer this paper operates on. In Noesis the
coincidence is a design target resting on the unbuilt cluster oracle, and the forge-cost is
*adversary-relative economic* (a funded actor can buy independent capital), not *physical-absolute*.
So the honest statement is "a proof relative to a capital-independence oracle," not "a proof."

## 5. Anchor and numeraire: what actually moved

A common objection from mechanism designers working on routing and coordination: there is no external
*numeraire*, no common cardinal unit in which players report the value of a contribution. The precise
answer separates two things the original draft fused:

- The **vesting predicate is ordinal and numeraire-free**: "did an independent-cluster mind build on
  this" is a binary check, no common unit of worth required.
- The **security of that predicate is cardinal and denominated in a numeraire after all** — and the
  numeraire is *standing itself*. The negative-EV result, the rent `rho`, the slash `sigma`, the
  break-even capital 9.00 (Section 6) are all magnitudes in standing units. The numeraire did not
  disappear; it moved from "the value of a contribution" into the EV model as "the value of
  independence-capital against harvest." So this is not a numeraire-free *truthful-revelation
  mechanism*. It is an *economic filter* priced in a standing numeraire. The paper claims only the
  latter.

For the same reason, drop the earlier "pricing the wait reveals a truthful preference": that is
revelation-principle language with no mechanism specified (no message space, payoff rule, or
equilibrium), and the actual revelation apparatus in the corpus, peer-prediction
(`DESIGN-harberger-peer-prediction-theorems.md`), has a truthful equilibrium that is *non-unique and
false in isolation*, rescued only by stake and dispute machinery this paper does not carry. "Price the
wait" is a *cost filter*, not preference revelation. And time is a *priceable cost* (true) but not a
*discriminator* between genuine and wash (false, and the corpus already knows it:
`DESIGN-mind-scarcity-asymmetry.md:3` records that patient adversaries beat every time-based filter,
airdrop farming, restaking points, wash-trading all survived; the wait taxes genuine and wash equally).

A dual failure the wash framing hides. "Mint nothing from nothing and there is nothing to wash"
addresses only *over*-crediting junk. The symmetric failure is *under*-crediting genuine value: a
contribution genuinely used by external parties who never post a capital-independent on-chain build edge
is invisible to the vesting gate, so it under-vests while its value is really realized. This is Samuelson
free-riding, and no-subsidy does not kill it. So the fee-backed-routing analogy is a rhyme, not an
isomorphism: a fee router prices at point-of-consumption in an actual numeraire with no free-riding
possible; vest-on-attested-build defers to an in-system edge that recurses (4a) and admits free-riding.

## 6. The receipt, and exactly which inputs are assumed

`node/examples/periphery_sim.rs` prices the boundary game:

```
genuine identity      EV = +19.35   (vests 0.75, survives challenge)
closed wash identity  EV = -36.00   (vests 0 by construction, pays rent)
break-even capital    =    9.00 / identity
```

The numbers reproduce exactly, but only *one* input is measured, and the rest carry the result:

- **Only harvest S = 45 is measured** on the real franchise (`periphery_sim.rs:5-9`). Rent `rho=0.30`,
  slash `sigma`, window, and the capital-independence source are *design parameters*.
- **Genuine vests 0.75, not 1.0**: the leaf cell has no independent child yet. This is the honest
  cold-start symmetry, at the frontier the gate *cannot distinguish a fresh honest cell from a wash
  cell* (both vest 0); early honest work is paid by the novelty floor, not this gate.
- **The +19.35 / −36.00 sign gap is driven by an assumed slash asymmetry** (`p_slash` wash = 0.5 vs
  genuine = 0.02, `periphery_sim.rs:85`), which presupposes a challenge process that *already tells junk
  from genuine* — the exact discernment Section 2 shows is impossible on-graph. So a per-decision judge
  re-enters through the dispute/slash door, and what adjudicates a challenge (and whether that
  adjudication is itself boundary-anchored) is an open assumption, not a closed one.
- **`vests 0 by construction`** is definitional: the sim *assigns* the ring one shared cluster, then
  measures that a one-cluster ring vests 0. The model prices the residual *after* detection; whether the
  protocol can detect the ring is one cluster is the unbuilt Layer A.
- **Falsification** (already latent in the sim): the closed-wash sign flips to **+9.0** the moment
  intra-ring leak passes ~80% (`rho + p_slash*sigma = 0.80`). The result holds only while the gate keeps
  leak below that and while junk is challenged materially more than genuine, both designed-not-built.

So this is a theorem in the EV model with a single measured input, not a shipped guarantee.

## 7. The attacker's ledger, and where it actually bottoms out

The residual is *not* uniformly "Bitcoin's 51%." That is true only for a funded-majority cartel. The
cheapest real attack is far below it. One table, so the boundary is legible rather than scattered:

| Attack | Gate verdict | Attacker cost | Handling / file:line |
|---|---|---|---|
| Free-keygen Sybil (mint identities) | stopped | fresh identity vests 0 | soulbound + vest gate, `lib.rs:7306` |
| Strictly-closed wash-ring | priced negative | rent + slash, EV −36 | `periphery_sim.rs`, vest 0 by construction |
| **Semi-funded ring (rent ONE distinct cluster)** | **LEAKS** | one 3rd-party identity per vested cell | `peer_prediction_sim.rs:154-170`, `a != b` |
| Capital-splitting whale | priced, not stopped | ~9.00 capital / identity | `lib.rs:7351`, `a != b` accepts split capital |
| Shared-prior / herding / semantic-copy "independent" builders | **open** | ~free past coordination γ*≈0.70 | `CALIBRATION-ci-argument`, pass `a != b` |
| Third-party-sybil | **open** | rent, not majority | `CALIBRATION-ci-argument`, capital proxy gap |
| Funded-majority cartel | priced (51%-class) | out-resource honest majority | Section 4a residual |

The sharpest single fact: the entire independence test is `(Some(a), Some(b)) => a != b`, so a
semi-funded ring that rents *one* distinct-cluster identity vests that cell **in full** and banks
partial standing "well below any 51% capture" (`peer_prediction_sim.rs:157-169`, a 2026-07-21
self-correction predating this paper). And capital-independence is, per the project's own calibration,
*necessary but not sufficient*: it closes the shared-controlling-capital channel only; shared prior,
herding, semantic copying, and third-party-sybil all pass `a != b`
(`CALIBRATION-ci-argument-2026-07-21.md:38-58`). The 51%-class analogy also over-imports structure:
Bitcoin's 51% is a majority threshold an attacker must out-resource *continuously*, whereas the boundary
game is a *linear per-identity capital toll* the attacker pays roughly once (standing is soulbound and
retained). So "51%-class" is the *funded-majority* residual, not the frontier.

## 8. Honest status (with receipts)

- **Built and tested:** the interior structural defenses, demonstrated 253/253 against *constructed*
  (not adaptive) adversaries (253 is the reference-node subset of a 359-test suite); the
  capital-independent vesting gate *logic* (`lib.rs:7306 pub mod vesting::independent_use_gate`,
  `node/tests/discernment.rs`) — but built as a pure function with exactly one call site (its own
  definition), **not wired into consensus**; the deployed value layer (`value_v5..v8`) gates on soulbound
  *standing*, not on this gate; the dispute market (`docs/DISPUTE-SLASHING.md`); soulbound identity and
  one-time leaf (`node/src/rpc.rs`, `runtime.rs`); the deterministic `ValueOracle` seam and its
  fixed-point novelty scorer (`lib.rs`).
- **Designed, not built:** Layer A's capital-independence *source* (the on-chain distinct-origin
  oracle, `lib.rs:7305`); Layer B's Harberger self-assessed rent; Layer C's `v(S)` retrained on
  realized-use labels.
- **Open:** the recursion base case (Section 4a); the semi-funded-ring leak and the shared-prior /
  third-party-sybil channels (Section 7); the learned `v(S)` on a real external signal (null on
  structural features, ~0.60 on honest rich-feature labels, which is honest-label prediction, not
  adversarial un-gameability); the Samuelson use-free-riding dual (Section 5); and the non-interference
  proof, that a compromised soft layer can degrade coordination but can never mint value or finalize a
  bad cell, which must land before any soft scoring layer ships.

## 9. One line

You cannot tell an honest contribution from a wash by looking at the graph. You do not fix that with a
better interior measure. You move the measurement to the boundary, which does not end the problem but
relocates it one level out and puts a price on it, and you make that price the mechanism. The honest
claim is not an un-gameable game. It is a game with *no free move*: interior gaming costs nothing, and
every boundary attack has a named, positive price, from one rented identity per cell at the cheap end to
out-resourcing the honest majority at the expensive end. Naming those prices, and which unbuilt piece
each one waits on, is the whole result.
