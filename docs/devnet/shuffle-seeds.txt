# Public shuffle seeds for the devnet replay check (docs/DESIGN-layer-map.md section 7).
#
# `factnode replay <trace> --seeds docs/devnet/shuffle-seeds.txt` replays a node's wire trace once in
# its own order and once per seed below, and fails if any run lands on a different hash or a
# different accept/reject count. The seeds are the plain integers 1 to 64, fixed before any run, so
# nobody can pick lucky ones. Order for a seed: Fisher-Yates over the trace entries, drawing j in 0..=i
# as splitmix64(state) % (i + 1), state starting at the seed (node/src/factsync.rs `shuffled_order`).
# To try your own seeds, pass any file with one decimal u64 per line.
